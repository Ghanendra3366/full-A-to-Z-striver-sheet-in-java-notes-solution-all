# How to Think Like a Programmer

1. Restate input/output. 2. Define constraints. 3. Solve a tiny example by hand. 4. Write a direct algorithm. 5. State the invariant. 6. Check complexity. 7. Test an empty, single, duplicate and extreme-value case. 8. Optimize only where constraints demand it.
