# Flowcharts and Pseudocode

Use a start/end oval, input/output parallelogram, process rectangle and decision diamond. Pseudocode example: READ n; IF n<2 RETURN false; FOR d=2 WHILE d<=n/d: IF n%d==0 RETURN false; RETURN true. Pseudocode describes the algorithm independently of Java syntax.
