# Learn Java

Java 8: `int` is signed 32-bit, `long` signed 64-bit; `boolean` is true/false. `(long)a*b` widens before multiplication. `a/b` truncates toward zero for integers. Arrays have fixed length and zero-based indices. Objects are passed by value of their reference; methods can mutate the referenced array. Strings are immutable: use `.equals`, not `==`. `StringBuilder` supports repeated appends. Use `public class Solution` in Solution.java. Compile with `javac Solution.java`, run with `java Solution`. Scanner is convenient; BufferedReader plus StringTokenizer is faster for large token streams. Never mix nextInt() and nextLine() without consuming the leftover newline.
