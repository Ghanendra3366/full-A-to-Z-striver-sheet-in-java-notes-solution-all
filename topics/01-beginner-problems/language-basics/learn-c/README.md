# Learn C++

Java comparison lesson: C++ vector corresponds roughly to ArrayList, unordered_map to HashMap, set to TreeSet, queue to ArrayDeque and priority_queue to PriorityQueue with a comparator. Java arrays do not resize; Java generics use boxed Integer rather than int. C++ pointers become object references, with null as the absent node. This Java-only repo does not provide C++ implementations.
